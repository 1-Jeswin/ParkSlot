# ParkSlot — Parking Facility Owner Module

> **Assigned Team Member:** Teammate 2  
> **Tech Stack:** Python 3.10+, Tkinter, SQLite  
> **Entry Point:** Run `python run_owner.py` from project root.

---

## 🎯 Scope & Screens Included (10 Screens)

1. **Owner Welcome Page:** Entry portal with Login, Register, and Exit buttons.
2. **Owner Registration Page:** Full Name, Email, Phone, Username, Password, Confirm Password with SHA-256 hash storage.
3. **Owner Login Page:** Authenticate facility owner credentials against `owners` table.
4. **Owner Dashboard:** Overview cards (Facilities, Total Slots, Available Slots, Booked/Occupied Slots, Total Bookings) + operations menu.
5. **My Profile Page:** View and update owner information.
6. **Parking Facility Registration Page:** Register new parking facility premises (Name, Location, Contact, Capacity, Operating Hours).
7. **Parking Slot Management Page:** Add slots per facility, specify vehicle category, floor/zone, and toggle availability.
8. **Booking Management Page:** Live view of driver reservations, vehicle registrations, and scheduled time windows.
9. **Parking Rate Management Page:** Define custom hourly tariffs for Cars, Bikes, and Other vehicle categories.
10. **Parking Records & Revenue Page:** Historical record logs with duration, collected fee calculation, and revenue aggregations.
