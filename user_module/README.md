# ParkSlot — User (Driver) Module

> **Assigned Team Member:** Teammate 1  
> **Tech Stack:** Python 3.10+, Tkinter, SQLite  
> **Entry Point:** Run `python run_user.py` from project root.

---

## 🎯 Scope & Screens Included (11 Screens)

1. **Welcome / Home Page:** Portal introduction with Login, Register, and Exit buttons.
2. **User Registration Page:** Full Name, Email, Phone, Username, Password, Confirm Password with validation and SHA-256 hash storage.
3. **User Login Page:** Username/Email + Password authentication.
4. **Forgot / Reset Password Page:** Account verification and password recovery.
5. **User Dashboard:** Live statistics (Vehicles, Available Slots, Total Bookings, Active Bookings) and quick action navigation.
6. **My Profile Page:** View and edit personal profile information.
7. **Vehicle Management Page:** Register new vehicle (Reg number, Car/Bike/Other, Model, Colour) and manage existing vehicles.
8. **Available Parking Slots Page:** Real-time search by location, facility, and vehicle type.
9. **Slot Booking Page:** Slot reservation with vehicle selector, date/time window, collision check, estimated fee calculation (`Duration * Rate`), and confirmation popup.
10. **My Bookings Page:** View upcoming, active, completed, and cancelled bookings with direct cancellation option.
11. **Fee Details Page:** Transparent fee calculation breakdown with duration and hourly tariff.
